# 1cTreeSchem

Внешняя обработка для 1С:Предприятие. По дереву узлов на форме она собирает текст схемы PlantUML в формате WBS (`@startwbs`) и запрашивает PNG у сервера рендеринга (по умолчанию `www.plantuml.com`). Готовое изображение показывается на форме. При открытии подставляется демонстрационное дерево оргструктуры.

Страница на Инфостарте: https://infostart.ru/1c/2119093/

## Как использовать

1. Откройте внешнюю обработку в 1С или зарегистрируйте её как дополнительную обработку: команда открывает форму. Для записи временного файла и HTTP-запроса обработке нужен небезопасный режим.
2. Отредактируйте дерево в колонке «Наименование» и при необходимости укажите заголовок схемы.
3. Нажмите «Сформировать». Текст схемы сжимается и отправляется на сервер рендеринга, PNG появляется в поле «Графическая схема». Сервер, ресурс и таймаут задаются на странице «Настройки».
